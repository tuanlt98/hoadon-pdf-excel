Hoá đơn PDF → Excel

Đọc hoá đơn GTGT điện tử (PDF hoặc XML) và gộp thành 1 file Excel. Xử lý ngay trên máy bạn — file không được tải lên máy chủ nào.

1 Chọn hoá đơn PDF / XML

hoặc kéo-thả file / thư mục PDF, XML vào đây

Khi chọn thư mục, trình duyệt có thể hỏi “tải lên” — thực chất chỉ là cho trang đọc file trên máy, không gửi đi đâu.

⚙ Cột bổ sung (tuỳ chọn)

File Excel đã có sẵn nhiều cột. Mục này chỉ dùng khi hoá đơn có trường khác mà bạn muốn lấy thêm.

Các cột đã có sẵn trong Excel

Cách thêm cột

  1. Chọn hoá đơn ở bước 1, rồi bấm 🔍 Dò trường trên hoá đơn — trang sẽ liệt kê mọi trường đọc được kèm giá trị ví dụ.
  2. Trường nào ghi “Đã có sẵn” thì không cần thêm. Trường muốn lấy thì bấm + Thêm.
  3. Sửa “Tên cột trong Excel” nếu muốn, chọn kiểu Chữ / Số / Ngày, rồi xuất Excel như bình thường.

Hoặc tự bấm + Thêm trường và gõ đúng chữ in trên hoá đơn (không cần dấu “:”, không phân biệt hoa thường/dấu). Thông tin chung = trường dạng “Nhãn : giá trị” (ra ở cả 2 sheet); Cột trong bảng hàng = tiêu đề cột trong bảng hàng hoá (ra ở sheet ChiTiet).

Cấu hình tự lưu trên trình duyệt này. Muốn dùng trên máy khác hoặc chia sẻ cho người khác: “Lưu cấu hình ra file” rồi gửi file đó để họ “Mở file cấu hình”.

2 Nơi lưu file Excel

Mẫu RX20 không có cột thuế suất. Dòng “Chiết khấu thương mại” được chia cho các mặt hàng cùng thuế suất theo tỷ lệ tiền. Mã thuốc = mã hàng trên hoá đơn; Đơn vị tính lấy chữ đầu (“Hộp 10 vỉ x 10 viên” → “Hộp”, phần đầy đủ ghi vào Quy cách đóng gói); Mã nhập hàng = số hoá đơn. Chi nhánh chọn trong hộp thoại tải lên của RX20.

Chưa có file nào
File Excel gồm 3 sheet: ChiTiet (mỗi dòng hàng 1 dòng), HoaDon (mỗi hoá đơn 1 dòng, có cột kiểm tra tổng), Loi (file cần xem lại). Nên dùng file XML nếu có (chính xác tuyệt đối). PDF chỉ đọc được bản có lớp chữ (bôi đen được chữ), không đọc được PDF scan/ảnh. Cùng 1 hoá đơn có cả PDF và XML thì chỉ lấy 1 lần (ưu tiên XML).
