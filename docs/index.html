Hoá đơn PDF → Excel

Đọc hoá đơn GTGT điện tử (PDF) và gộp thành 1 file Excel. Xử lý ngay trên máy bạn — file không được tải lên máy chủ nào.

1 Chọn hoá đơn PDF

hoặc kéo-thả file / thư mục PDF vào đây

Khi chọn thư mục, trình duyệt có thể hỏi “tải lên” — thực chất chỉ là cho trang đọc file trên máy, không gửi đi đâu.

⚙ Cột bổ sung (tuỳ chọn)

Lấy thêm trường không có sẵn trong file Excel. Gõ đúng chữ in trên hoá đơn (không cần dấu hai chấm, không phân biệt hoa thường/dấu).

  • Thông tin chung: trường dạng “Nhãn : giá trị” ở phần đầu/cuối hoá đơn, vd Mã khách hàng, Số hợp đồng, Ghi chú. Ra ở cả sheet ChiTiet và HoaDon.
  • Cột trong bảng hàng: tiêu đề một cột của bảng hàng hoá, vd Nước sản xuất, Chiết khấu (%). Ra ở sheet ChiTiet.

Cấu hình tự lưu trên trình duyệt này. Muốn dùng trên máy khác hoặc chia sẻ cho người khác: “Lưu cấu hình ra file” rồi gửi file đó để họ “Mở file cấu hình”.
